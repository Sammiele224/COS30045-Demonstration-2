Exercise 4.1 · SVG house

A house and garden built from SVG primitives. Hover, focus, or select a part to inspect how it is drawn. Developer Tools shows the coordinates, shared window group and transforms.

House and garden

Try the sun, door, windows, cloud and flowers.

Select a house part to learn which SVG shapes make it.
