HOW TO EXPLAIN IT

From values to bars

d3.csv() loads each row as text, so +d.count converts a count into a number. scaleLinear() turns counts into widths. scaleBand() gives each brand a row and a bar height. The SVG viewBox lets the result resize with the page.
